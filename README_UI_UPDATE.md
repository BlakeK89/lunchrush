This release matches the approved Shelf Life / Brand Rundown interface system:

- Electric-blue settings sidebar with styled dataset controls
- Large original Lunch Rush logo and brand divider
- Cream reporting-period context
- Five compact KPI cards and supporting AUV
- Horizontal navigation tabs (Overview, Restaurants, Channels & Dayparts, Menu Performance, Insights)
